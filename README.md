# Ecosistema NovaSolum — Material Comercial

Material oficial de ventas y presentación del ecosistema NovaSolum.

## 📄 Contenido

- **`guia_ventas_novasolum.html`** — Guía comercial & presentación interactiva (manual para asesores de ventas + presentación para clientes).
  - 📸 Capturas reales de los sistemas (NovAI CRM, GeoNova360, FarmaNova POS, NovaFood)
  - 🔍 Lightbox para ampliar imágenes con botón de cierre
  - ✨ Animaciones suaves al hacer scroll
  - 🎨 Identidad NovaSolum (morado profundo + verde esmeralda)

- **`capturas/`** — Capturas de pantalla reales de cada sistema:
  - `NovAI/` — CRM & ventas (12 capturas)
  - `GeoNova360/` — Panel geoespacial (5 capturas)
  - `FarmaNova/` — POS farmacéutico (6 capturas)
  - `NovaFood/` — Restaurantes & delivery (13 capturas)
  - `_recursos/` — Logos y recursos compartidos

## 🚀 Cómo actualizar

1. Editar la presentación en `guia_ventas_novasolum.html`
2. Añadir/actualizar capturas en `capturas/`
3. Commit y push a `main` — GitHub Pages publica automáticamente
